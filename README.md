# 永慶高中財產報廢與轉移系統 v9

## 從 v8 更新

替換 `Index.html`，儲存後發佈新部署版本。主頁籤分為「查詢財產」「財產報廢與轉移」「作業清單」「匯入財產盤點 Excel」「系統管理」。作業清單內可切換四張清單。

## 從 v7 更新

替換 `Tasks.gs` 與 `Index.html`，儲存後發佈新部署版本。作業清單分成四個頁籤，每次顯示所選清單。待報廢及待轉移可勾選多筆後按「確定處理」或「放棄」。放棄前會顯示勾選筆數並要求確認，只刪除勾選的待辦登記。比對失敗或需要人工選擇的資料仍留在原頁籤。

## 更新 v4 至 v6

替換 `Code.gs`、`Tasks.gs` 與 `Index.html`。儲存後先執行 `setup`，它會在「待辦登記」加上「已比對財產編號」欄，再至「部署 → 管理部署作業」發佈新版本。

首頁同時顯示「待報廢財產」「已準備報廢」「待轉移財產」「已準備轉移」。按「確定處理」後，若比對到唯一財產，登記會立即移至對應的已準備清單。多筆符合時可選用正確財產，查無資料時可手動查找。勾選待辦後按「放棄」，經確認後刪除選取的登記。

從已準備清單按「加入申請單」可核對明細。報廢可合併多筆，轉移請逐筆處理。建立申請單後，已準備清單用申請單呈現這批財產，可列印或下載 Word。辦結後，申請單移至歷史。取消已建立的申請單後，已比對的登記回到已準備清單。

## 從 v3 更新

替換 `Code.gs`、`Forms.gs`、`Tasks.gs`、`Index.html`，儲存後至「部署 → 管理部署作業」發佈新版本。

主頁有「財產報廢與轉移」「匯入財產盤點 Excel」「系統管理」三個頁籤。財產報廢與轉移頁可輸入編號查詢，也可直接按「登記報廢」或「登記轉移」把編號帶入待辦。查不到時顯示「系統無資料」，仍可先登記。之後從待辦按「比對財產」，選定現行財產並建立申請單。申請紀錄提供「列印」與「下載 Word」兩種方式，使用同一組欄位與資料。瀏覽器列印會另開預覽，下載 Word 則沿用原範本版面。

## 從 v2 更新

替換 `Code.gs`、`Forms.gs`、`Tasks.gs` 和 `Index.html`，儲存後至「部署 → 管理部署作業」發佈新版本。

「系統管理 → 清除全部資料」清除五張系統工作表表頭以下的系統欄位資料，保留表頭、格式與其他頁籤。需要輸入完整確認文字並再次確認。

報廢 Word 的「已使用年月」依購置日期至產出當日計算，以臺灣時間為準。重新下載會依當日重新計算，表單日期同步更新。「使用年限」沿用清冊欄位。

## 從 v1 更新或首次安裝

1. 從指定的 Google 試算表開啟「擴充功能 → Apps Script」。
2. 替換 `Code.gs`、`Forms.gs`、`Import.gs` 與 `Index.html`，新增 `Tasks.gs`。既有的 `Templates.gs` 可繼續使用。
3. 檢查 `appsscript.json` 中 `enabledAdvancedServices` 的 Sheets 服務只出現一次。若 Sheets 已啟用，沿用原設定。ZIP 也附有可供新專案使用的資訊清單。
4. 儲存並執行 `setup`。它會建立「待辦登記」，保留既有清冊和申請紀錄。首次安裝請貼入 ZIP 內的所有程式檔，再執行 `setup`。
5. 選「部署 → 管理部署作業」，編輯既有部署並選擇「新版本」後部署。首次安裝選「新增部署作業 → 網頁應用程式」，執行身分選「我」，存取權選「僅限我」。

## 操作

1. 在「待報廢」填機器編號，保管人姓名可稍後確認，或在「待移轉」填財產編號、新保管人至少一項。登記會寫入 Google 試算表。
2. 待辦的「比對財產」會以登記的編號預先搜尋。機身貼紙編號找不到時，按「改用保管人查詢」，或手動輸入財產編號。只登記新保管人的移轉，請輸入財產編號或原保管人找出要移轉的設備。
3. 選定財產後，確認明細並建立申請單。移轉會帶入登記的新保管人，請補移入單位與地點。待報廢可以合併送單，待移轉仍逐筆送單。直接從查詢頁加入財產的原有多筆送單方式仍可使用。
4. 下載原格式 Word 表單。報廢原因預設「年限已到不堪使用」，報廢金額請送單前核對。
5. 庶務組辦結後，至「申請紀錄」按「完成並清除」。系統歸檔成功後才從待辦清單移除，原登記與申請紀錄仍存於試算表。取消申請單後，原登記可重新比對與送單。
6. 匯入在「匯入財產盤點 Excel」頁籤。財產名稱預設「個人電腦」，以 Sheet1 的財產名稱欄精確比對。預覽會顯示符合、略過、重複、已歸檔、異常等筆數。確認寫入後會顯示實際寫入筆數。既有匯入資料保留。
